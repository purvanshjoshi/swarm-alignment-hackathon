# Additional material

Supporting documents for the Swarm Alignment Hackathon submission **“Who’s in Charge? Authority Verification and Boundary Decisions in a Shared Agent Channel”** (Purvansh Joshi, Graphic Era Hill University, Dehradun). The submitted 8-page report is [`docs/report/Purvansh_Joshi_Apart_Submission.pdf`](../report/Purvansh_Joshi_Apart_Submission.pdf).

| # | Document | What it is |
|---|---|---|
| 1 | [Extended paper](01_extended_paper.md) | Full-length version of the submission with 8 figures, the same findings, plus verbatim prompts and stimuli, the reason-labelling protocol, complete statistics, and research declarations (data availability, ethics, CRediT, competing interests, funding) |
| 2 | [Data and reproducibility card](02_data_and_reproducibility_card.md) | What every data file contains, how to regenerate every number and figure, known issues |
| 3 | [Simulated peer review](03_simulated_peer_review.md) | AI-generated review panel: round 1 on the submission, round 2 on the extended version with figures. It is **not** an independent human review. |
| 4 | [One-page brief](04_one_page_brief.md) | Plain-language summary for practitioners |
| 5 | [Statistics supplement](statistics_supplement.md) and [`cells.csv`](cells.csv) | Every per-cell rate, Wilson interval, verification count and Fisher test, generated by `python -m ladder.supplement` |
| 6 | [Integrity and citation check](05_integrity_and_citation_check.md) | Every number recomputed from the data, and every reference checked against its source (AI-generated, following the academic-pipeline and deep-research skills) |
| 7 | [Figures](figures/) | Eight numbered figures (PNG + PDF) used in the documents above: study design, edit rates, same-text provenance comparison, defence effect, verification vs editing, stated reasons, edit timing, labeller agreement |
| 8 | [Interactive dashboard](interactive/index.html) | Hover-enabled charts for every cell and an episode explorer: filter by model, condition, defence and outcome, then read any agent's board, reasoning and actions turn by turn. **Download the file and open it in a browser** (GitHub shows HTML as source). |

All numbers come from the released data in `code/ladder/results/main/` and are regenerated by the scripts in `code/ladder/ladder/`. Figures: `python -m ladder.extra_figures`; dashboard: `python -m ladder.dashboard`. PDF versions of documents 1–4 and 6 are in this [Google Drive folder](https://drive.google.com/drive/folders/1lqb_leD2D5F2mJBvpBGJtTMG0Q7wFdlp?usp=sharing). These documents were prepared with AI assistance (Claude, using the open-source academic-research-skills by Cheng-I Wu, CC BY-NC 4.0), as described in each document's AI-use statement.
